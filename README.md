# CrickCraft 🏏

### Built for Real Cricket Conditions

CrickCraft is a mobile-first cricket training and performance tracking app designed to help players practice smarter, track performance, improve fitness, and receive expert feedback.

## Project Overview

Amateur and district-level cricket players often manage their training through notebooks, WhatsApp, and multiple disconnected apps.

CrickCraft brings training, fitness, performance tracking, expert feedback, and match preparation into one place.

## Research

* 8 User Interviews
* 25 Survey Responses
* 3 User Personas
* 10 Usability Test Participants

## Key Insights

* 72% of players follow unstructured practice routines
* 60% do not consistently track their performance
* 68% prefer an all-in-one cricket platform
* 48% lack regular coach feedback

## Key Features

* Structured Practice Planning
* Performance Tracking
* Shot Analysis
* Fitness Tracking
* Expert Feedback
* Match Updates
* Clubs
* Weekly Performance Reports
* Match Readiness Score
